## How it works

A chat assistant waits for you to ask, then replies. An agent is given a goal and some tools. The tools might be access to an inbox, a spreadsheet, a calendar or a business system. The agent works out the steps, takes them, looks at the result and carries on until the task is done or it needs help.

How much freedom an agent has is a design choice. A well-designed agent in a small business has a narrow job, access only to what that job needs, and a clear point where it stops and a person approves the work before anything is sent or changed.

Singapore's IMDA has published a [Model AI Governance Framework for Agentic AI](https://www.imda.gov.sg/-/media/imda/files/news-and-events/media-room/media-releases/2026/01/factsheet-model-ai-governance-framework-for-agentic-ai.pdf). Its factsheet recommends assessing the risks upfront, setting limits on an agent's autonomy, tools and data access, triggering human approvals at significant checkpoints, and rolling agents out gradually, starting with certain users or features.

## An example

A property management company receives maintenance requests from tenants by email and web form. An agent reads each request, sorts it by urgency, checks the unit's records, drafts a work order for the right contractor and drafts a reply to the tenant. Then it stops. A coordinator reviews both drafts, adjusts anything that needs it and approves them. Nothing reaches a contractor or a tenant until a person has said yes.

## AI agent vs AI assistant

An AI assistant answers you one request at a time, and you decide what happens next. An AI agent works through several steps by itself towards a goal. Many tools now offer a bit of both, so the useful question is how many steps the tool takes before a person looks.
